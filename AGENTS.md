# Веб-приложения для чата с LLM-моделью

### Краткое описание
Подробностей пока нету. На текущий момент, нужно составить скелет
архитектуру. Для примера, нужно составить сервис пользователя и
ответ от LLM (В данный момент, вместо LLM, будет 10 случайных ответов)

### Стек
CI\CD: Docker compose
Backend: FastAPI, SQLAlchemy, PostgresSQL
Migration: FlyWay migration
